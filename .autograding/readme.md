# Autograding setup for the exercise

This folder contains the autograding setup for the exercise repository. It runs the tests, collects points, and converts test results into the `result.json` format expected by Classroom50-compatible graders.


## What this folder does

1. Runs tests with Vitest.
2. Stores raw test output in JSON format.
3. Converts that output into a scoring report with environment metadata.


## Files and folders

* `.gitignore`
  Ignores files that should not be committed from this folder (dependencies and generated results)

* `.npmrc`
  Defines npm safety settings for this autograding environment

* `package.json`
  Declares scripts and dependencies for the autograder (`test` and `report`).

* `package-lock.json`
  Lockfile generated by npm.

* `readme.md`
  This documentation file for the `.autograding` folder.

* `results-vitest.json` (generated)
  Raw JSON output created by `npm run test`, input for report conversion in `src/prepare-report.ts`.

* `src/prepare-report.ts`
  Reads Vitest JSON, calculates the score, adds Classroom50 environment metadata and writes final JSON to an output file path.

* `src/types.ts`
  TypeScript type definitions used by the report converter.

* `tests/linux-commands.test.ts`
  Vitest test suite for the student command scripts. Uses `zx` to execute shell commands and inspect results.

* `tsconfig.json`
  TypeScript configuration for this folder.


## Typical workflow

```sh
npm install
npm test
npm run report
```

This workflow will generate files `results-vitest.json` and `../result.json`.
